Entry for make.fun's "Invent a Word We Need" bounty ($5 in USDC).

## The word

**draftgrave** — a long message you typed out, then deleted instead of sending.

## Run it

```sh
python3 main.py
```

The program writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when that variable is unset).
